# Демо вашего праздника

MVP для ведущего и клиента: короткая анкета → игра-подъём по этапам тайминга → правка минут → PDF.

Репозиторий: [StasShmatd-lang/timing](https://github.com/StasShmatd-lang/timing).

## Что умеет

1. Старт: имя, пол (силуэт), фото лица для аватара в игре.
2. Анкета 8–10 вопросов с ветками **Юбилей / Свадьба / Корпоратив**.
3. Название события и компании подставляется в тексты, где уместно.
4. Тайминг собирается по режиссуре: welcome, тосты / слово руководителя, интерактив, гастропауза 15 мин, обряды / знакомство через фото, конкурсы, танцы, дискотека 2×30 + пауза.
5. Doodle-подъём: аватар с лицом клиента, 2 касания на этап, текст открывается постепенно.
6. Всплывающий ведущий (`brand/host-face.jpg`), сцена «официант → координатор» на гастропаузе.
7. Итог: правка минут и скачивание PDF.
8. Единое лого: `brand/logo.png`.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (по умолчанию `http://127.0.0.1:5173`).

Сборка:

```bash
npm run build
npm run preview
```
