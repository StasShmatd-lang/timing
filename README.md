# Демо вашего праздника

MVP для ведущего и клиента: короткая анкета → игра-подъём по этапам тайминга → правка минут → PDF.

Репозиторий: [StasShmatd-lang/timing](https://github.com/StasShmatd-lang/timing).

## Что умеет

1. Старт по центру: имя, силуэт, фото лица для аватара.
2. Анкета организатора: 4 секции на ветку (число в названии = число вопросов), ветки **Юбилей / Свадьба / Корпоратив**.
3. Название события и компании в текстах; смысл, пик, бар, танцевальная дуга.
4. Тайминг по режиссуре: welcome, тосты / слово руководителя, интерактив, гастропауза, обряды / знакомство через фото, конкурсы, танцы, дискотека 2×30.
5. Игра как уровень Mario: аватар бежит вперёд по этапам, пройденное остаётся сзади.
6. Всплывающий ведущий (`brand/host-face.jpg`), сцена «официант → координатор».
7. Итог: правка минут и PDF.
8. Лого: `brand/logo.png`.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (по умолчанию `http://127.0.0.1:5173`).

Сборка:

```bash
npm run build
npm run preview
```
